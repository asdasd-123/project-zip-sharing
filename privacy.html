Privacy policy

How the desktop utility handles Google Drive data.

The utility requests Drive access to locate existing synced ZIP files and manage their sharing permissions. It reads file and folder names, identifiers, checksums and permissions. It calculates a checksum from the local ZIP. Google processes the API requests. The viewer URL is returned to the calling program, which may retain it in its history. Anyone with the link can access the ZIP.

The offline credential is stored on the Windows computer using Windows account encryption. The utility does not send ZIP contents or credentials to this website, sell Google user data, or use Google user data for advertising.

The operator can revoke access in Google Account connections, remove the local credential, or restrict a shared file in Drive. Revoking the app does not withdraw existing viewer links. Contact the operator using the support email on the consent screen for privacy questions.
